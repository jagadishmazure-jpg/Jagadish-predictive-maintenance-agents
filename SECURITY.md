# Security policy

This is a synthetic-data demo repo. If you find a genuine security issue in
the guardrail logic (gateway bypass, audit tampering, PII leak), please open
a GitHub issue — do not include any real personal data in the report.

## Scope notes
- No live systems, no real plant data, no production credentials.
- The RUL model is illustrative, not a calibrated prognostics model.
- Secret scanning and push protection are enabled on the repository.
